NetSilcon Maze Simulator

A virtual rover driven by the exact int8 NetSilcon-64x6 network that runs on the Tang Nano 20K FPGA. Every 50 ms a 360° LiDAR becomes 16 inputs, the chip maths returns speed and steering, and fixed logic adds a safety stop and a 3-point-turn helper. Find the exit in the top-right corner.

Two model files, one chip. Both networks have the same shape (16 → 64 × 6 → 16) and the same 16 LiDAR inputs. The rover model only learned to avoid obstacles. The maze model learned the right-hand rule: turn right if you can, else go straight, else turn left, and stop at a dead end so the 3-point-turn helper can turn the rover around.

Test results (Python simulation, 80 mazes the models never saw): maze model reached the exit in 72 of 80 mazes with 0 crashes; rover model in 38 of 80 with 1 crash. This page is a JavaScript copy of that simulation: the network maths is bit-exact, the physics follows the same equations.
